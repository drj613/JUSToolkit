# Game Reference

General game-system reference distilled from fan-written GameFAQs guides
(unverified community claims — treat numbers as hypotheses). Moved here from
the jus_re battle-mechanics research repo because they document the game's
economy and menus rather than in-battle mechanics.

- **j-gem.md** — J-Gem currency: drop amounts by kill type, ranking/Wi-Fi/quiz
  rewards, farming routes. Source: gf-52886.
- **wireless-mode.md** — Wireless/Wi-Fi menu structure, match-setup rules,
  deck trading, deck password system. Source: gf-46526.

Source URL pattern:
`https://gamefaqs.gamespot.com/ds/933199-jump-ultimate-stars/faqs/<id>`
(fetchable via the Wayback Machine; GameFAQs blocks direct scraping).
