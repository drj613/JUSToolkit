## Help/Support koma

**Help koma:** attached character's special (SP) gauge regenerates while on the field.

**2-koma support** ("Hokuto Gokin Bundan Kyaku", Type: Power)
- Hits: 2
- Damage: 20 / 20 / 30 (Power/Laughter/Knowledge)
- Inflicts speed-down status

- Hits: 11
- Damage: 23+2+4 / 23+2+4 / 34+3+6 (base + follow-up add-on damage, Power/Laughter/Knowledge)
- Can knock opponent through breakable floors

## Mechanic-revealing observations

- Neutral+Y is stated to increase the hit count of Forward+Y and Up+Y when used first (author unconfirmed exact mechanism).
- Up+Y (mashable, 14 hits) can be canceled into a special before the move finishes — used as a combo tool (cancel window exists before animation completion).
- 4/5-koma specials described as combo-friendly (fast startup); 6/7/8-koma specials described as having slow startup, requiring combo adjustments (skip extra Up+Y hits to fit timing).
- 8-koma Special B (Musou Tensei) is a counter/reversal triggered by being hit, with an invincibility window afterward.
- Support koma summoned mid-Up+Y or mid-special are used to extend combos (juggle state persists through support koma hits).
