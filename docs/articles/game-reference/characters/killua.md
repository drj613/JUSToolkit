## Acquisition / Evolution

- Unlocked in the first set of worlds (planet is adjacent to One Piece's, in the "middle atmosphere" area per author's description).
- Help Koma unlock condition: win the first mission's point-based objective by a margin of **4 or more points** than the opponent (author unconfirmed exact scoring mechanic, described only as "get more points").
- Evolution path: Help Koma -> 2 Support unlocks -> 2 Battle Koma unlocks (no gem costs listed in this guide).

## Basic Moveset

No numeric damage values are given anywhere in this guide — only move descriptions.

| Input | Description |
|---|---|
| Y | Yo-yos in circular motion, combos into a follow-up attack |
| Left/Right + Y | Lunges and claws enemy's face; good combo-finisher / edge-out tool |
| Up + Y | Yo-yo thrown into the air (hits above), then swings back to hit in front; hits multiple targets |
| Down + Y | Guard break via claw attack (author: "not the best" guard break) |
| B | Weak hit, close range |
| Left/Right + B | Throws yo-yo in the chosen direction |
| Up + B | Quick yo-yo toss upward; author calls it "one of Killua's worse attacks" |
| Down + B | Quick forward lightning motion; briefly stuns enemy, sets up a follow-up special |
| A | Jump |
| Select | Ultimate Action: power-up stance (referencing Greed Island); slowly increases special (SP) gauge — no rate given |

### 4-Koma Specials
- X: Steals a gem quickly from opponent; Killua ends up on the opposite side from the one he hit on. Notable for edge-escape utility.
- Up+X: Powers Killua up quickly, then leaves him in a "blind" state for about **5 seconds**; author says it enables "massive damage" during that window but doesn't attack the opponent directly ("don't attack its weak point" — meaning don't use it if vulnerable). (author unconfirmed exact effect of "blind" state — unclear if this is a self-buff window or literal blindness debuff)

### 5-Koma Specials
- X: Creates clones of himself while walking forward; anyone hit is blasted with lightning and can't recover (tumbles) until landing. Useful for edge-outs.
- Up+X: Jumps up and fires an energy beam downward. Described as good for surprising an airborne-unaware opponent below.

## Help / Support Koma

- Help Koma: Boosts Gon's strength (no number given); also grants immunity to lightning-attack effects for the attached character.
- Support Koma 2: Quick version of the 5-Koma Up+X special; useful defensively while blocking against an approaching foe.
- Support Koma 3: Randomized effect ("roll of a dice") — either damages the user or heals them. Author recommends only using it when at very low health.

## Mechanic-revealing observations

- Left/Right+Y into B is called out as Killua's best combo and functions as an "instant kill" against an opponent already past the stage edge — confirmed to work on the Naruto/One Piece stage pits, including on the Naruto stage even when the pit isn't visibly "open" (suggests off-screen/edge hit detection extends beyond the visible pit opening).
- Author states most of Killua's yo-yo-based attacks are "controllable" mid-move — e.g., the aerial Y attack can be redirected to hit a diagonally-positioned target after the first hit lands, implying some moves have an input-adjustable trajectory phase after initial activation.
- Enemies hit by the 5-Koma X special are stated to be unable to recover ("tumble") until they land — an untech/knockdown-state interaction.

## Deck notes (non-numeric)

- Characters listed as boosting/powering-up Killua via Help Koma placement: Gon, Nico Robin, Killua (self). No boost magnitude given.
