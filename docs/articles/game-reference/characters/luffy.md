## Combo/mechanic-revealing notes (author's routes, listed for hitstun/cancel info)
- "B, Forward B, Forward Y" — basic bread-and-butter cancel chain into Bazooka, used for ring-outs.
- "B, Up B, Forward Y" — Stamp into Bazooka.
- "B, Up B, Up Y" — Stamp into Shotgun (Pistol); author notes this route leaves you open if Shotgun whiffs.
- "B, Forward B, Forward/Neutral X" — basic moves cancel into forward specials (4/6/7/8 Koma X moves).
- "Up B, Up Y, Golden Peony/Storm (Horizontal)" — author notes ALL hits of the Shotgun/Pistol move (11 hits) must land for the target to be launched into the air (a hit-count-gated launch threshold — mechanically notable: implies partial hit connections do not produce the launch/knockdown state, only completing the full multi-hit sequence does).
- Support-assisted combos referencing "Trunks" (3-Koma and 2-Koma support, from another character's koma) landing alongside Bazooka doubles knockback if timed to hit simultaneously with the support's final blast (author unconfirmed precise timing window).
