# Support Koma Catalog (Jump Ultimate Stars)

- **Source guide:** "Support Guide" v1.1, by shinyspark
- **GameFAQs FAQ id:** gf-49288 (file `49288-support-faq.txt`)
- **Reliability:** Unverified community claim source — a fan FAQ, not extracted from game data. Numbers, ranges, and delays are the author's own estimates/observations (author admits some effect names may be misremembered/inconsistent). Treat all values as hypotheses to verify against emulator/ROM data.

## Terminology used by the author

Range categories (subjective, measured against the author's "testing stage"):

| Term | Meaning |
|---|---|
| Impressive range | Entire stage |
| Great range | Between impressive and nice |
| Nice range | About a screen away |
| Half-screen | Half a screen away |
| Short range | Between half-screen and minimal |
| Minimal range | Right next to caller up to just a bit ahead |
| Infinite/Unlimited range | No apparent limit (stated explicitly for some supports) |

Delay categories (author's frame/beat counting, approximate):

| Term | Meaning |
|---|---|
| No delay | Effect happens immediately on summon |
| Short delay | ~1-2 count before effect |
| Medium delay | ~3-4 count before effect |
| Long delay | ~5+ count before effect |

Abbreviations used below: **SD** = short delay, **MD** = medium delay, **LD** = long delay, **ND** = no delay.

Support koma have two versions per character-slot in the game: a size-2 koma and a size-3 koma, each with independent effects. Not every character has both listed by the author (some series only got a 3-koma entry).

## Implementation-relevant notes

- Every support koma appears to have exactly two versions tied to koma size (2 and 3); size 3 is not simply "bigger numbers" — it's frequently a distinct move/effect from size 2, sometimes with lower damage but different behavior (e.g., Kurita 2 does 39 dmg single-hit vs Kurita 3 does 30 dmg multi-hit).
- SP drain effects are commonly specified as a fraction/count of "SP bars" (values seen: 3/4 bar, 7/8 bar, 1, 2, 3, 4 bars) — suggests SP is tracked as discrete bars but supports can take fractional-bar amounts.
- Damage values are the author's observed maximums; several supports have variable/randomized or distance-scaled damage (author explicitly notes non-fixed values):
  - Franky 3: 37-75 max damage, scales with distance from opponent (farther = longer charge = more damage) (author unconfirmed exact curve).
  - Momoshiro 2: 22 initial + ricochet up to 23 more = 45 max total.
  - Killua 3: fully random outcome — full heal, drop to 1 HP, or half heal.
  - Luckyman 2: random status from {Shock, Poison, Blindness}.
  - Higure 2: effect (Blindness vs Speed-Down) depends on distance to opponent.
- Guard-break flag is a distinct property from damage/status — tracked separately in the Guard-Break list (12 known supports flagged as guard-breaking).
- Range and delay are the author's own descriptive bucket system, not measured frame data — needs recalibration against actual game timing/hitbox data during reimplementation.
